# Security

## Supported versions

Security fixes are applied to the latest released version unless stated otherwise.

## Reporting a vulnerability

Do not publish credentials, private keys, tokens or exploit details in a public issue.

If GitHub private vulnerability reporting is available for this repository, use it. Otherwise, open a minimal public issue asking for a private contact method without including exploit details.

Include the affected Nebula version, Windows version, reproduction conditions and expected impact.

## Local data

Nebula stores configuration and command history under `%APPDATA%\Nebula` by default. Command history may contain sensitive command-line arguments. Avoid placing secrets directly on command lines when possible.
